# ICP

Updated: 2026-09-07

## What we sell (even if not for sale yet)

**Company OS** — a file-based operator harness (`AGENTS.md` + `skills/*/SKILL.md` + wiki/SOPs + correction → eval + traces). Week-1 money loop: market research → draft outreach (human must `APPROVE_SEND`). Not a multi-agent orchestration SaaS. Not “autonomous C-suite by Friday.”

Status: **open template / dogfood** — not a priced product yet. Do not quote a price.

## Primary

- Founders and 1–5 person teams already running LLM agents for GTM (research, outbound drafts, CRM notes)
- Pain: agents repeat the same mistakes; corrections die in chat; no skill/SOP/eval promotion loop
- Trigger: a near-miss wrong send, a bad public draft, or the third time fixing the same tone/fact error
- Fit signals: already uses Cursor/Hermes/OpenCode (or similar); comfortable with git + markdown; will approve external actions

## Anti-ICP

- Buyers who want fully autonomous send/post/charge without human gates
- Teams wanting a no-code multi-agent “department” demo before one measured loop works
- Enterprises needing SOC2/SSO/SaaS procurement this quarter (we are not that product yet)
