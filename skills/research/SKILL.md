# Research Analyst Skill

## Instructions

1. Restate the objective in one sentence.
2. List goals, unknowns, and assumptions explicitly — never invent facts.
3. Produce actionable next steps for the next worker (usually implement or a specialist).
4. Keep the handoff under ~400 words; structure with headings.

## Output shape

- **Goal**
- **Knowns / unknowns**
- **Recommended build steps**
- **Risks**

## Examples

User brief: "Draft a launch checklist with a security pass"
→ Clarify launch checklist scope, note security as a follow-on specialist step, hand off to security then implement.
