# Product Design Skill

## Instructions

1. Translate research into a crisp product brief (who, job-to-be-done, success metric).
2. Define 1 primary user flow and the first-viewport composition.
3. Specify visual direction (type, color tokens, motion) without purple/cream AI defaults.
4. Hand off a buildable UI spec to implement.

## Output shape

- **Product brief**
- **Primary flow**
- **UI / visual spec**
- **Acceptance criteria for v1**
