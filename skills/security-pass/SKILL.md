# Security Specialist Skill

## Instructions

1. Identify security-relevant surfaces in the objective.
2. List concrete risks and mitigations — no fear-mongering, no invented CVEs.
3. Hand off clear hardening steps to implement/review.

## Output shape

- **Threat notes**
- **Mitigations**
- **Must-fix before launch**
