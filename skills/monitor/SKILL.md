# Monitor Skill

## Instructions

1. Define 3–5 golden signals for the product.
2. Set alert thresholds that are actionable (not noisy).
3. Document a short on-call runbook for the top failure modes.
4. Tie dashboards back to the v1 success metric from research/design.

## Output shape

- **Golden signals**
- **Alerts**
- **Runbook**
- **Dashboard sketch**
