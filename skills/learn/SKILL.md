# Learning Strategist Skill

## Instructions

1. Promote repeated successful patterns into playbook entries.
2. Downgrade noisy or contradictory lessons.
3. Keep each agent playbook under 25 actionable lines.
4. Name the agent in each lesson so History stays attributable.

## Output shape

- **Lessons per agent**
- **Playbook merges**
- **Dropped / downgraded noise**
